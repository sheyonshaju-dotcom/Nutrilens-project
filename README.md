# 🍽️ NutriLens

## 📌 Overview

NutriLens is a web-based application that recommends healthy meals based on user-provided ingredients. It helps users discover recipes, view nutritional details, and contribute their own recipes.

---

## 🚀 Features

* Ingredient-based recipe recommendation
* Detailed nutrition information
* User-submitted recipes
* Recipe images and instructions
* Simple and user-friendly interface

---

## 🛠️ Technologies Used

* Python (Flask)
* HTML, CSS, JavaScript
* SQLite Database

---

## 📂 Project Structure

* `app.py` – Main Flask application
* `templates/` – HTML pages
* `static/` – CSS, JS, images
* `nutrilens.db` – Database

---

## ▶️ How to Run

1. Install dependencies
2. Run:

   ```
   python app.py
   ```
3. Open browser: `http://127.0.0.1:5000/`
